# kotlin-racing-car

### 프로그램 소개

---

이 프로그램은 경기에 참가하는 자동차 이름의 리스트와 경기에서 진행될 라운드의 횟수를 입력받으면, 입력한 자동차끼리 경주를 한 결과와 우승자를 출력해주는 프로그램입니다.

### 기능 목록

---

- [x] 접수 관리자는 입력받은 참가자들의 이름이 유효한지 결정한다.
  - **입력 예외 처리**
    - [x] 이름의 길이가 5자를 초과하는 경우
    - [x] 이름에 알파벳과 숫자외의 요소가 들어간 경우
    - [x] 이름 목록이 올바른 형태(빈 칸 없이 쉼표로 구분된 형태)를 따르지 않는 경우
    - [x] 이름 목록에 중복이 있는 경우
  - [x] 유효한 입력에 한해서 등록을 처리한다.
- [x] 경주 관리자는 진행될 라운드의 횟수를 입력받아 결정한다.
  - **입력 예외 처리**
    - [x] 라운드의 횟수가 양의 정수가 아닌 경우
- [x] 경기는 라운드마다 다음을 반복하는 것으로 이루어진다.
  - [x] 모든 자동차가 랜덤한 숫자를 생성하고 그 숫자가 4이상인 경우에만 전진하고 경기 진행상황을 출력한다.
- [x] 경주가 끝나면 경주 관리자는 가장 앞서있는 최종 우승자를 출력한다.

### 사용법

---

```
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
예시) a,b,c,d,e,f
```
```
시도할 횟수는 몇 회인가요?
예시) 10
```
